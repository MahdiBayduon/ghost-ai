# Ghost AI

An interactive systems architecture builder built with Next.js, React, TypeScript, Tailwind CSS, and UI components from Base UI and shadcn.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` to check the production build.

## Project structure

- `app/` - routes and application entry points
- `components/` - interface components
- `context/` - shared application state
- `lib/` - supporting utilities

This is an evolving project; see the code for the current feature set.
